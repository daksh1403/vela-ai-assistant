# Royal monochrome theme

A restrained black-and-white palette across overview, chat, image studio, and voice room. Dark mode uses charcoal #171717, raised panels #202020, neutral borders #383838, and white #f5f5f5 for text and primary actions. Light mode uses white panels on #fafafa with black #171717 actions. Existing typography and layout remain.

The ribbon orb, canvas illustration, chrome sphere, inspiration photographs, status accents, and review banner use silver and neutral gray. Generated images retain their original colors. Hover, keyboard focus, selected navigation, loading, and disabled states retain visible distinctions. Error messages retain their explicit text and icon cues. Browser theme metadata follows the selected mode.
